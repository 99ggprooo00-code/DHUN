## DHUN 1.00.001 — public pre-release

DHUN is a GPL-3.0 music player for Android and Windows desktop. It uses YouTube Music as an anonymous catalogue and playback source; DHUN does not ask for a DHUN account or sign-in. This is the first fixed, versioned pre-release. It is **experimental**, not stable, store-ready, or fully accepted on real hardware.

### Current features

- **Discover and browse:** Home feed, search, artist/album/playlist pages, related tracks, and radio playback.
- **Listen:** Android background playback with notification/media controls; mini-player, full player, queue, shuffle, and repeat.
- **Keep a library:** liked songs, local playlists, listening history, and app-private downloads for offline playback.
- **More controls:** lyrics when available, appearance settings, and playback preferences.
- **Windows desktop:** tray controls, operating-system media controls, taskbar jump lists, and a 10-band equaliser. Playback needs a system VLC/libVLC installation.
- **Android compatibility work:** Android 7.0+ (API 24); the pre-31 launch path is isolated from Compose class loading, and older Android uses a dimmed artwork fallback instead of unsupported blur.

The browser interface is an engineering preview only. It does not provide audible playback.

### Installation

Download the platform asset and its `.sha256` sidecar from this release. Verify the checksum before installing; the full steps are in [`docs/INSTALL.md`](https://github.com/99ggprooo00-code/DHUN/blob/main/docs/INSTALL.md).

**Android:** Install `dhun-v1.00.001.apk` (universal) on Android 7.0 or newer. Allow your file manager/browser to install unknown apps if prompted. The ABI-specific APKs are optional. Uninstalling DHUN deletes its app-private library and downloads.

**Windows:** Install `dhun-v1.00.001.msi` per user. SmartScreen may warn because the MSI is unsigned. Install VLC separately for audio. The optional yt-dlp fallback is not bundled. Back up `%LOCALAPPDATA%\DHUN\userdata` before updating and quit DHUN from the tray first.

### Test-build and support notice

- The Android APK is signed with the repository's **public throwaway test key**. It is not a Google Play signing key; this build is not Play-upload-ready.
- The Windows MSI is **not Authenticode-signed**. Its internal MSI ProductVersion is an installer-upgrade counter and is separate from the DHUN version.
- YouTube controls the endpoints DHUN uses. Extraction can break or be restricted, so playback availability is not guaranteed.
- Green builds and automated tests do not prove real-device playback, audio quality, battery behavior, or every installation/upgrade path. Android and desktop hardware acceptance is still in progress.
- This pre-release is for testing, not a daily-use device. Report issues without sharing cookies, credentials, tokens, or signed media URLs.

The rolling `test` build is a separate **private draft** restricted to repository collaborators and is replaced on main updates. This versioned pre-release is the fixed public build for this release.
