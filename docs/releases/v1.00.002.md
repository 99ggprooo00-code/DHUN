## DHUN 1.00.002 — public pre-release

DHUN is a GPL-3.0 music player for Android and Windows. This fixed public release includes the merged work since `v1.00.001` (including PRs #154–#167), **not just the most recent visual-tuning change**. It is experimental, not store-ready or fully accepted on real hardware.

### What's new since 1.00.001

- **Settings and appearance:** a categorized Settings hub, Black (OLED) theme, live backdrop blur and brightness controls, clearer reading surfaces, and better-balanced light/dark glass. Tonal surfaces are fixed at **15%** in the public app. The experimental per-component sliders and theme catalogue remain **test-build-only** and are not shown in this release.
- **Lyrics:** enhanced word-synced LRC playback, per-song lyric resync and match selection, provider preferences, optional on-device romanization and offline translation, plus local TTML import. With CC open, the player’s ⋮ menu offers lyric-specific controls instead of track actions.
- **App and playback controls:** improved player/mini-player surfaces, queue presentation, playback preferences and data controls; in-app About & Legal pages on Android and Windows. Existing queue material retains its opaque backing in the public build.
- **Release safety:** verified Android package identity for all three APKs, versionCode **7** (up from 6), and an increasing Windows MSI ProductVersion with the same UpgradeCode. The hosted Windows installer check exercises installation over the earlier public MSI with seeded userdata and cache sentinels.

The browser app is an engineering preview and does not provide audible playback. The website changes made since 1.00.001 are not an indication that the browser player is complete.

### Install and upgrade

Download an asset and its matching `.sha256` sidecar from this release, verify the checksum, then follow [the installation guide](https://github.com/99ggprooo00-code/DHUN/blob/main/docs/INSTALL.md).

- **Android 7.0+**: `dhun-v1.00.002.apk` is universal; the `arm64-v8a` and `armeabi-v7a` APKs are optional. It uses the same **public throwaway test key** as the previous public build. Android should allow updating public `v1.00.001` (versionCode 6) to this build (7). **A rolling test APK has a much higher versionCode and cannot be replaced in place by this public APK.** Back up what matters before uninstalling a test build: uninstalling removes app-private library data and downloads.
- **Windows**: `dhun-v1.00.002.msi` installs per user. Quit DHUN from its tray before updating, back up `%LOCALAPPDATA%\DHUN\userdata`, and install VLC separately for desktop audio. The installer is unsigned, so SmartScreen may warn. The MSI’s internal version is an upgrade sequence, not the app version.

### Testing boundaries

- The Android APK is debug-built and signed with a public test key, not a Play signing key. The Windows MSI is not Authenticode-signed. Neither build is store-ready or recommended for a daily-use device.
- CI validates builds, JVM/Android tests, packaged APK identities, MSI identity and a hosted-Windows install-over with seeded userdata/cache sentinels. This does **not** prove launch, playback, visuals, data preservation on your device, or compatibility with every installed test build.
- YouTube Music and lyrics providers can change or restrict their endpoints; playback and lyric availability are not guaranteed. Report failures without sharing credentials, cookies, tokens or signed stream URLs.

The rolling `test` draft is separate and private to collaborators. Its test-only UI sliders and catalogue are **not** part of this public pre-release.
