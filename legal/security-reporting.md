Please report security problems privately. This project has **no private
reporting channel enabled yet**, so the interim procedure below is what applies
today. It is reproduced from the repository's own security policy, in full.

The interim channel is [a public issue titled "Security contact
request"](https://github.com/99ggprooo00-code/DHUN/issues/new) containing **no
technical detail** — the maintainer replies there with a private way to send the
report.
